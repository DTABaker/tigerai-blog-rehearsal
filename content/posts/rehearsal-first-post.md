## What this page tests

This is a deliberately labeled rehearsal post for the TigerAI blog workshop, not a claim about a student or a professional accomplishment. The repository was generated from the public workshop template in a separate project repository, leaving the existing personal blog in place.

## The editing loop

The rehearsal uses the live personalization studio to download a settings file and a Markdown draft. The downloaded settings are committed into the copy's content folder, and the draft is placed in its posts folder. GitHub Actions builds the site and GitHub Pages serves the result under the repository's own path.

![Three steps: edit text, commit the file, and publish the website.](/assets/uploads/rehearsal-flow.svg)

This image checks an uploaded asset and its accessible description. The post title, summary, and Rehearsal topic provide distinct ways to find this page in the writing archive.

## A useful distinction

Saving a source file and publishing a page are separate steps. A successful workflow is the checkpoint before reviewing the live result. The next rehearsal checks intentionally invalid settings, recovery, and the removal of instructional samples from the generated site. Students should replace their own prompts with accurate writing and review their work before sharing a professional link.
